# ID Card Portrait Design

## Goal

Display the user's supplied portrait on the front of the portfolio's existing interactive lanyard ID card, then run the site locally.

## Scope and approach

- Preserve the attached source image by copying it to a new descriptive filename under `public/assets/`.
- Update only the front-image reference in `components/sections/LanyardSection.js`.
- Keep the current back image, card appearance, interactions, and all unrelated site content unchanged.
- Start the existing Next.js development server and report its local URL.

## Verification

Confirm the new asset is served by the app, run an available build or focused check, and report whether the dev server starts successfully. Do not overwrite or stage unrelated existing workspace changes.
